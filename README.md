## 快速使用

1. 在两台 Android 设备上安装同一版本的应用，并将它们接入**同一个可信的局域网**。支持 Android 7.0 及以上系统。
2. 在用于查看和操作的手机上点击**接收投屏**或**显示我的二维码**，保持二维码页面打开。
3. 在被查看的手机上点击**扫码连接**或**发送投屏**，扫描接收手机的二维码，然后按系统提示允许录制或共享屏幕。两台手机可以交换角色，按相同步骤反向连接。
4. 如需操作被查看的手机，在该手机的投屏页面点击**允许本次远程控制**，按提示在系统无障碍设置中手动启用本应用的远程控制服务，返回后再次点击并确认。在接收手机上点击**控制**，即可单指点击、滑动，并使用**返回**、**主页**按钮。
5. 结束时，在任一端点击**结束投屏**。停止或断线后，本次控制授权自动失效。

自动发现仍可用于普通投屏；搜索不到时，扫码直接使用二维码中的 Wi-Fi 地址连接。手动输入 IP 也可用于普通投屏，但**远程控制仅在扫码配对的会话中可用**。如果两台手机连接同一 Wi-Fi 后仍无法连接，请确认路由器未开启客户端隔离。`<unknown ssid>` 仅表示 Android 未向应用提供网络名称；界面会改为显示 Wi-Fi 连接状态，实际连接使用网络接口的 IPv4 地址。

如需调整画质，可在开始投屏前进入**设置**，修改分辨率、码率、画面填充方式或帧率。帧率可选 30、60、120 fps；**120 fps 为实验性选项**，实际帧率还受设备屏幕、编码器、解码器与网络条件限制。选择“等比缩放”可保留完整画面，选择铺满模式可能裁剪边缘。

## 功能与限制

- **低延迟局域网投屏**：画面在发送端与接收端之间传输，不依赖云端中转。实际延迟并非固定值，会随设备性能、画质设置和 Wi-Fi 状态变化。
- **免费、无广告**：当前公开版本无需付费，也未集成广告 SDK。
- **可选音频投送**：系统声音采集需要 Android 10 及以上系统，部分应用会禁止被采集；麦克风模式需要相应权限。音频效果以设备和应用兼容性为准。
- **扫码与控制**：二维码包含本次接收页面的随机配对码。控制还要求被控手机的系统无障碍授权和每次投屏时的明确确认。当前支持单指点击、滑动、返回和主页。
- **请仅在可信局域网使用**：视频和控制数据连接没有端到端加密；二维码配对码不是加密协议。不要在公共或不可信 Wi-Fi 上使用，也不要向他人展示二维码。

如果安装包提示“无法覆盖安装”，可能是旧版与当前正式版的签名证书不同。卸载旧版后可以重新安装，**卸载会清除该应用的本地设置**。

## 从源码构建

使用 Android SDK 与 JDK 构建调试版：

```bash
./gradlew assembleDebug
```

Windows PowerShell 可使用 `./gradlew.bat assembleDebug`。调试 APK 位于 `app/build/outputs/apk/debug/`，使用 `.dev` 包名，可与原版并存。正式版签名私钥不包含在公开仓库中；原版 Release 安装包没有上述新功能。
