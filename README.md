## 快速使用

1. 在两台 Android 设备上安装同一版本的应用，并将它们接入**同一个可信的局域网**：连接同一 Wi-Fi，或在主力机开启个人热点、让另一台手机连入。支持 Android 7.0 及以上系统。
2. 在用于查看和操作的手机上点击**接收投屏**或**显示我的二维码**，保持二维码页面打开。
3. 在被查看的手机上点击**扫码连接**或**发送投屏**。可以扫描接收手机的二维码，也可以点发现列表中的“连接”或手动输入接收手机 IP；随后按系统提示允许录制或共享屏幕。两台手机可以交换角色，按相同步骤反向连接。
4. 如需操作被查看的手机，在该手机的投屏页面点击**允许本次远程控制**，按提示在系统无障碍设置中手动启用本应用的远程控制服务。返回应用后会再次询问是否允许当前会话。在接收手机上点击**控制**，即可单指点击、滑动，并使用**返回**、**主页**按钮。
5. 结束时，在任一端点击**结束投屏**。停止或断线后，本次控制授权自动失效。

### 全屏与操作栏

发送手机的“接收端全屏”只改变接收手机的显示方式，保留整幅画面和触摸位置，不再强制发送手机横屏或重建采集。接收手机右侧的“操作”按钮始终可打开控制栏；栏会在 5 秒后隐藏，隐藏后不会挡住触摸。控制栏分为连接操作与返回、主页、恢复亮度两行。接收手机按系统返回键会先退出全屏或控制模式，不会直接断开连接。“结束并反向”会先提示当前连接将结束。

某些厂商系统会在离开无障碍设置后关闭服务，应用无法代替用户重新开启系统开关。此时发送页会显示“开启系统控制服务”，并在返回设置页后再次检查；可以查看该系统是否要求同时开启服务快捷方式或允许后台运行。若系统开关持续自动关闭，需要在该手机上排查系统限制。

### 主设备最低亮度模式（实验）

1. 连接投屏，并在主设备点击“允许本次远程控制”。主设备须已在系统无障碍设置中启用本应用的远程控制服务。
2. 在主设备投屏页点击“主机极暗（实验）”，确认后会用透明的无障碍窗口把**主设备物理亮度调到系统允许的最低值**，并保持屏幕逻辑上点亮。画面没有盖黑层，接收端应继续显示和操作。无需 Root、Shizuku 或“修改系统设置”权限。
3. 可在接收端进入“控制”，点击“恢复主设备亮度”；也可在主设备再次点击“恢复主机亮度”。结束投屏、撤销本次控制或无障碍服务停止时也会移除调暗窗口。
4. **这不是物理显示面板断电**：OLED 可能接近全黑，部分 LCD 或厂商系统仍会微亮，或不接受窗口亮度覆盖。请在你的两台手机上验证。按实体电源键可能触发锁屏并由 Android 结束屏幕采集；本版不再因为普通的“屏幕关闭”广播自行暂停采集，但无法阻止系统结束授权。

自动发现、扫码和手动 IP 都可以建立投屏，并在被控手机明确允许本次控制后操作，不需为控制再扫码。扫码中的随机码仍会核对目标接收页。扫码连接只验证二维码格式和 IPv4 地址有效性，不再按地址段或厂商系统报告的网段预先拦截；是否可达由实际网络连接判断。如果无法连接，请确认两台手机确实在同一 Wi-Fi 或热点网段，并检查路由器或热点没有阻断设备互访。`<unknown ssid>` 仅表示 Android 未向应用提供网络名称；界面会显示本地无线网络状态，实际连接使用网络接口的 IPv4 地址。

如需调整画质，可在开始投屏前进入**设置**，修改分辨率、码率、画面填充方式或帧率。帧率可选 30、60、120 fps；**120 fps 为实验性选项**，实际帧率还受设备屏幕、编码器、解码器与网络条件限制。选择“等比缩放”可保留完整画面，选择铺满模式可能裁剪边缘。

### 一台手机开个人热点

在主力机系统设置里开启**个人热点**，让接收画面的手机连接它。接收手机打开本应用的“接收投屏”页并显示二维码；主力机扫描该码发起投屏。两台手机不需要再连接第三个 Wi-Fi。连接会依次尝试相符的 Wi-Fi 路径、系统默认路径和备用 Wi-Fi 路径。热点通常由手机系统设置开启，本应用不能在普通应用权限下直接替你打开运营商共享热点。热点模式请优先扫码；不同厂商的自动发现行为可能不同。

## 功能与限制

- **低延迟局域网投屏**：画面在发送端与接收端之间传输，不依赖云端中转。实际延迟并非固定值，会随设备性能、画质设置和 Wi-Fi 状态变化。
- **免费、无广告**：当前公开版本无需付费，也未集成广告 SDK。
- **可选音频投送**：系统声音采集需要 Android 10 及以上系统，部分应用会禁止被采集；麦克风模式需要相应权限。音频效果以设备和应用兼容性为准。
- **扫码与控制**：二维码包含本次接收页面的随机码；发现列表或手动 IP 也可连接。无论如何连接，控制均要求被控手机的系统无障碍授权和每次投屏时的明确确认。当前支持单指点击、滑动、返回和主页。
- **请仅在可信局域网使用**：视频和控制数据连接没有端到端加密；二维码配对码不是加密协议。不要在公共或不可信 Wi-Fi 上使用，也不要向他人展示二维码。

1.1.5-dev 可以覆盖同签名的 1.1.2–1.1.4 实验版，并与 1.1.1-dev 并存。如果安装同标识版本时提示“无法覆盖安装”，可能是签名证书不同；卸载那个同标识应用会清除它自己的本地设置。

## 从源码构建

使用 Android SDK 与 JDK 构建调试版：

```bash
./gradlew assembleDebug
```

Windows PowerShell 可使用 `./gradlew.bat assembleDebug`。调试 APK 位于 `app/build/outputs/apk/debug/`，使用 `.experiment` 包名，可与已有的 1.1.1 版并存。正式版签名私钥不包含在公开仓库中；原版 Release 安装包没有上述新功能。
