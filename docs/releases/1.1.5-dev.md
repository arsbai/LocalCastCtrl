# 局域投屏控制LocalCastCtrl 1.1.5-dev

感谢 [cwe88108](https://github.com/cwe88108) 开发并开放源码 [LocalCastPro](https://github.com/cwe88108/LocalCastPro)。本项目遵循原项目的 Apache License 2.0 许可，并保留原项目的提交历史。扫码配对、双机远程控制及以下改动属于本衍生版本。

## 本次更新

- **同一 Wi-Fi 或手机热点连接**：一台手机开启个人热点，另一台加入后即可扫码、通过发现列表或手动 IP 建立投屏；也修复了部分设备显示 `0.0.0.0`、无法发现设备，以及有效局域网二维码被误判的问题。热点由手机系统开启，应用不会代替系统打开热点。若路由器或热点禁止设备互访，连接仍可能失败。
- **扫码与远程控制**：每台手机都可以显示自己的配对二维码。自动发现、扫码和手动 IP 建立的投屏会话，均可在发送手机明确允许后进行点击、滑动、返回和主页操作，不需为控制再次扫码。发送手机还需在系统无障碍设置中启用远程控制服务。
- **主设备最低亮度模式（实验）**：在投屏并授权控制后，可把发送手机物理屏幕亮度降至系统允许的最低值，接收手机继续查看和操作。它不会锁屏，也**不等于关闭显示面板**；部分屏幕仍会微亮，按电源键可能使系统结束采集。无需 Root 或 Shizuku，可从接收端恢复亮度。
- **全屏与控制栏**：接收端全屏改为等比显示完整画面，不再强制发送端横屏或重建采集。接收端边缘保留“操作”按钮；控制栏隐藏后不挡住画面触摸。返回、主页和恢复亮度按钮分行显示。
- **控制授权提示**：从系统无障碍设置返回后重新检查服务状态，并继续本次会话的授权流程。若厂商系统自动关闭服务，应用会提示检查系统开关；普通应用无法强制保持系统无障碍服务开启。
- **图标**：改为两台手机与双向交互箭头。

## 安装与验证

两台手机请安装同一份 `LocalCastCtrl-1.1.5-dev.apk`。本 APK 的包名为 `com.localcast.pro.experiment`、版本号为 17，使用与先前 1.1.2–1.1.4 本地实验版相同的调试签名，可覆盖它们；与 1.1.1-dev 的 `com.localcast.pro.dev` 并存。

源码已通过本地 `assembleDebug` 和 `testDebugUnitTest`，APK 已验证签名。此前双机投屏与控制有用户实测反馈；本次 1.1.5 改动仍需在不同机型上验证。请仅在可信局域网使用，当前视频与控制连接没有端到端加密。
